# M-Bedrock Development Brief

Use only for genuinely cross-owner or ambiguous development where a normal bounded/standard contract cannot yet be trusted.

## Brief

```text
Goal
User-visible success metric
Non-goals / forbidden proxies
Competing semantic owners
Material unknowns
First separating evidence
Execution context and proof ceiling
GitHub-verifiable partition
Higher-context residue
Acceptance
STOP condition
```

Resolve only enough ambiguity to select one primary owner, then STOP this skill and hand off to that specialist.

Do not use this skill merely because a task is large, quality-sensitive, or involves several files.
