# Audit Run History

Historical selected-map audit executions and evaluation runs live here.

Categories:

- `developer-notes/` — developer-note extraction/coverage runs.
- `full-map/` — full-map audit execution records.
- `manual/` — explicitly recorded manual/runtime crosschecks.
- `post-upgrade/` — post-upgrade validation campaigns.
- `prospective/` — prospective/unseen audit evaluations and runtime-validation records.
- `regression/` — known regression audit runs.
- `runtime-queue-reduction/` — historical runtime-queue reduction campaigns.
- `unseen/` — blind/unseen-map evaluation runs.

These files are historical execution evidence. They are not current gameplay truth, current report authority, planning state, or durable audit procedure.

Current issue truth remains in the canonical current report. Reusable lessons must be deliberately promoted into reliability catalogs/corpus rather than inferred directly from historical run output.
