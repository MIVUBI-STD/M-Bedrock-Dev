# Rules Agent Rules

Applies to Bedrock/Education compatibility and semantic rule data.

## Rules

- Every rule states applicable edition/version/capability scope.
- Stable/current, preview/beta, experimental, and Education-specific behavior remain distinguishable.
- Prefer data/capability profiles when behavior is declarative.
- Do not scatter version gates across unrelated parsers.
- Do not broaden supported versions from assumption.
- External rule data needs provenance and update semantics.
- A rule does not become runtime proof merely because authoritative documentation supports it.
