# Engineering Contract Catalogs

Global MIVUBI Engineering Contracts. These are implementation/validation requirements, not Minecraft facts and not Map Game Design.

They may guide implementation and QA. They are not loaded as Minecraft platform knowledge by default and are not Game Design authority.


## Canonical naming

- filenames use `*-contract.json`;
- source authority is `engineering-contract`;
- item classification is `engineering-contract`;
- `policy` / `project-policy` are historical aliases only.

Runtime-domain groups mirror platform vocabulary: `platform`, `world-engine`, `player-runtime`, `entity-runtime`, and `gameplay-runtime`.
