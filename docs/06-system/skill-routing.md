# Skill Routing

Skills encode stable repeated execution procedures, not languages or file types.

## Specialist set

```text
m-bedrock-artifact-engineering
m-bedrock-content-analysis
m-bedrock-repair-engineering
m-bedrock-compatibility
m-bedrock-development-brief
```

## Routing

Artifact/container/workspace/package decision:
→ `m-bedrock-artifact-engineering`

Manifest/function/command/reference/graph/diagnostic semantic analysis:
→ `m-bedrock-content-analysis`

Patch planning, transactional mutation, coordinate/topology repair:
→ `m-bedrock-repair-engineering`

Version/edition/feature compatibility or Bedrock-vs-Education behavior:
→ `m-bedrock-compatibility`

Cross-owner ambiguity where success criteria or ownership cannot yet be frozen:
→ `m-bedrock-development-brief`

## Handoff rule

```text
Owner A decides + proves its boundary
→ emit minimum typed result
→ STOP Owner A
→ Owner B consumes result without recomputing Owner A truth
```

Do not load multiple specialists merely because a request mentions several file types.
