# System

This domain owns architecture, semantic ownership, development discipline, specialist routing, and developer/delivery operations.

Canonical entrypoints:

- `development-discipline.md` — how much to build and how to avoid overdevelopment;
- `implementation-map.md` — exact semantic/source owners;
- `skill-routing.md` — specialist selection and handoff;
- `development-operations.md` — developer command, toolchain, verification and delivery routing;
- `architecture.md` — dependency direction and subsystem boundaries.

Do not turn audit notes or temporary migration plans into durable parallel owners.
