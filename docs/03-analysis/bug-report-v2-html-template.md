# Bug Report V2 HTML Template

## Required Sections

```text
01 Overview
02 Gameplay Flow
03 Game Design Reference
04 Bug Dashboard
05 Confirmed Bugs
06 Needs Validation
07 Reproduction Guide
08 Audit Coverage
```

```text
BUG-ID
```

## Writing Rules

Tester-facing text must use:

- World
- Player
- Level
- Wave
- Arena
- Enemy

Avoid exposing internal implementation terms unless inside Evidence.
