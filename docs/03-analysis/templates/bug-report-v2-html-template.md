# Bug Report V2 HTML Template Contract

## Document Structure

```text
01 Overview
02 Gameplay Flow
03 Game Design Reference
04 Bug Dashboard
05 Confirmed Bugs
06 Needs Validation
07 Reproduction Guide
08 Audit Coverage
```

## Bug Entry

```text
BUG ID

Category

Gameplay Flow

Severity

Status

Issue

Player Impact

How To Reproduce

Expected Behavior

Actual Behavior

Evidence
```

## Reader Priority

The report must be understandable by:

- QA tester
- map developer
- reviewer

Reproduction steps must describe player actions inside the World, not internal implementation details.
