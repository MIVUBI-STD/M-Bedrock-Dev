# Derived Topology Candidates

Topology candidates are evidence-backed repeated spatial patterns.

A candidate records:

- a base effect;
- member effects;
- translation from base for each member;
- translation-invariant shape identity;
- evidence count;
- confidence.

Confidence is intentionally simple at first:

- 2 matching members → low;
- 3–4 → medium;
- 5+ → high.

Confidence is not a gameplay verdict. It describes repeated-pattern evidence only.

Outlier comparison is separate. Given an expected translation, the analyzer compares the actual translation and returns match, outlier, or not-comparable.
