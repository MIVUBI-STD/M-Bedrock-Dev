# Production HTML Report Structure

```text
World Bug Report
|
├── Overview
├── Gameplay Flow
├── Game Design Reference
├── Bug Dashboard
├── Confirmed Bugs
├── Needs Validation
├── Reproduction Guide
└── Audit Coverage
```

Each bug detail:

```text
Bug ID
Category
Gameplay Flow
Severity
Status
Issue
Player Impact
Reproduce Steps
Expected Behavior
Actual Behavior
Evidence
```

The report is a QA handoff document, not an internal analyzer dump.
