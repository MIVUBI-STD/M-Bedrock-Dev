# Project Planning

Compact continuation index for project-specific work.

Detailed artifacts, evidence, patches, reports, and execution state remain under `workspace/`. This file should only record concise planning pointers when a project needs follow-up.

## Active projects

No project-specific planning entries are migrated here yet. Existing active project execution remains unchanged until the repository migration map identifies the canonical owner for each current item.

## Rule

Keep entries concise:

```text
project-id
→ objective
→ next action
→ blocker, if any
→ canonical workspace/report reference
```

Do not duplicate audit findings, evidence, report content, or Work Session state here.
